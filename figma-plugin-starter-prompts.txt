# Figma Plugin Starter Project Prompts

## Option 1: React + Vite Figma Plugin

Create a new Figma plugin project with React and Vite using the following structure:

### Project Setup
```
npm init -y
npm install --save-dev typescript @types/node vite @vitejs/plugin-react
npm install --save-dev @figma/plugin-typings
npm install --save-dev vite-plugin-singlefile vite-plugin-generate-file
npm install --save-dev vite-plugin-react-rich-svg postcss postcss-url
npm install --save-dev rimraf npm-run-all
npm install --save-dev jest ts-jest @types/jest jest-environment-jsdom
npm install --save-dev @testing-library/react @testing-library/jest-dom
npm install --save-dev sass autoprefixer
npm install react react-dom
npm install monorepo-networker
```

### File Structure
Create the following directory structure:
```
src/
├── common/
│   └── networkSides.ts
├── plugin/
│   ├── plugin.ts
│   └── plugin.network.ts
├── ui/
│   ├── index.html
│   ├── main.tsx
│   ├── app.tsx
│   ├── components/
│   ├── styles/
│   │   └── main.scss
│   └── store/
└── setupTests.ts
```

```json
{
```

**figma.manifest.ts:**
```typescript
export default {
  name: "Your Plugin Name",
  id: "YOUR_PLUGIN_ID", // Replace with your actual plugin ID
  api: "1.0.0",
  main: "plugin.js",
  ui: "index.html",
  capabilities: [],
  enableProposedApi: false,
  editorType: ["figma", "figjam"],

```

**vite.config.plugin.ts:**
```typescript
import path from "node:path";
import { defineConfig } from "vite";
import generateFile from "vite-plugin-generate-file";
import { viteSingleFile } from "vite-plugin-singlefile";
import figmaManifest from "./figma.manifest";

export default defineConfig(({ mode }) => ({
  plugins: [
    viteSingleFile(),
    generateFile({
      type: "json",
      output: "./manifest.json",
      data: figmaManifest,
    }),
  ],
  build: {
    minify: mode === 'production',
    sourcemap: mode !== 'production' ? 'inline' : false,
    target: 'es2017',
    emptyOutDir: false,
    outDir: path.resolve("dist"),
    rollupOptions: {
      input: path.resolve('src/plugin/plugin.ts'),
      output: {
        entryFileNames: 'plugin.js',
      },
    },
  },
  resolve: {
    alias: {
      "@common": path.resolve("src/common"),
      "@plugin": path.resolve("src/plugin"),
    },
  },
}));
```

**vite.config.ui.ts:**
```typescript
import { defineConfig } from "vite";
import path from "node:path";
import { viteSingleFile } from "vite-plugin-singlefile";
import react from "@vitejs/plugin-react";
import richSvg from "vite-plugin-react-rich-svg";
import postcssUrl from "postcss-url";

export default defineConfig(({ mode }) => ({
  plugins: [react(), richSvg(), viteSingleFile()],
  root: path.resolve("src/ui"),
  build: {
    minify: mode === "production",
    cssMinify: mode === "production",
    sourcemap: mode !== "production" ? "inline" : false,
    emptyOutDir: false,
    outDir: path.resolve("dist"),
    rollupOptions: {
      input: path.resolve("src/ui/index.html"),
    },
  },
  css: {
    postcss: {
      plugins: [postcssUrl({ url: "inline" })],
    },
    preprocessorOptions: {
      scss: {
        api: "modern-compiler",
      },
    },
  },
  resolve: {
    alias: {
      "@common": path.resolve("src/common"),
      "@ui": path.resolve("src/ui"),
    },
  },
}));
```

### Key Features
- Two-side architecture (plugin + UI)
- Type-safe communication via monorepo-networker
- React 18 with TypeScript
- Vite for fast development and building
- Jest testing setup
- SCSS support with modern compiler
- Path aliases for clean imports
- SVG support with rich-svg plugin
- Single file output for Figma

### Key Differences from React
- Uses @preact/preset-vite instead of @vitejs/plugin-react
- Uses @testing-library/preact instead of @testing-library/react
- JSX import source set to "preact" in tsconfig
- Smaller bundle size and faster performance
- Same API as React for easy migration

### Development Workflow
1. Run `npm run dev` to start development with hot reloading
2. Run `npm run build` to create production build
3. Run `npm test` to run Jest tests
4. Run `npm run types` to check TypeScript types
5. Load the plugin in Figma by pointing to the `dist` folder

### Notes
- Replace "YOUR_PLUGIN_ID" with your actual Figma plugin ID
- Both versions support the same development workflow
- Preact version has smaller bundle size (~3KB vs ~42KB for React)
- Choose React if you need wider ecosystem support
- Choose Preact if you prioritize performance and smaller bundle size
