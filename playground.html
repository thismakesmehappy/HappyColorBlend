NumberToggle Component

Default NumberToggle

Basic NumberToggle with no min/max constraints.

const [value, setValue] = useState(5); <NumberToggle decreaseFunction={() => setValue(value - 1)} increaseFunction={() => setValue(value + 1)} value={value} />

NumberToggle with Min Value

NumberToggle with a minimum value of 1. The decrease button should be disabled when value is 1.

const [value, setValue] = useState(3); <NumberToggle decreaseFunction={() => setValue(value - 1)} increaseFunction={() => setValue(value + 1)} minValue={1} value={value} />

NumberToggle with Max Value

NumberToggle with a maximum value of 10. The increase button should be disabled when value is 10.

const [value, setValue] = useState(8); <NumberToggle decreaseFunction={() => setValue(value - 1)} increaseFunction={() => setValue(value + 1)} maxValue={10} value={value} />

NumberToggle with Min and Max Values

NumberToggle with a range of 1-10. Both buttons should be disabled at their respective limits.

const [value, setValue] = useState(5); <NumberToggle decreaseFunction={() => setValue(value - 1)} increaseFunction={() => setValue(value + 1)} minValue={1} maxValue={10} value={value} />
